How Traid works

A forecast has to survive context.

The chart is the output. Behind it, Traid separates model generation from the logic used to judge which path deserves to be shown.

01

Read the market

Completed candles, the current market state and higher-timeframe structure establish the context available at prediction time.

02

Generate possible futures

Kronos samples multiple legitimate OHLC trajectories instead of reducing the future to a single up-or-down call.

03

Rank the paths

Traid checks structure, liquidity, session, volatility, multi-timeframe alignment and scheduled economic risk before selecting a representative path.

04

Track what happens

The selected forecast stays visible beside real price. Traid can score direction, close error, ATR-normalized error and how the path changes as reality arrives.

Replay

Do not trust a forecast because it looks convincing.

Pick a historical cutoff. Traid hides everything after it, runs the same forecasting stack against only the information available at that moment, then lets you reveal what actually happened candle by candle.

More than a model output

Context decides whether a prediction deserves attention.

Kronos paths

Multiple sampled future OHLC sequences form the raw candidate set.

Market structure

Swings, BOS / CHoCH, liquidity, fair value gaps, order blocks and dealing-range position provide structural context.

Multiple timeframes

Higher-timeframe bias, setup location and lower-timeframe trigger can agree, conflict or produce no-trade conditions.

Regime + session

Volatility and trading-session conditions help distinguish a quiet range from an expansion environment.

Economic events

Scheduled high-impact events are treated as risk context rather than automatic trade instructions.

Calibration

Realized forecasts can teach Traid which kinds of predictions have historically held up under similar conditions.
